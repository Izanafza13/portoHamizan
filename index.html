Riset Skripsi

Klasifikasi Kesesuaian Lahan untuk Budidaya Padi Menggunakan Ensemble Machine Learning

Membangun model klasifikasi kesesuaian lahan padi berbasis ensemble machine learning (Decision Tree, Random Forest, dan XGBoost dengan Hard & Soft Voting), menggunakan data lapangan dari Kecamatan Kamal, Bangkalan.

Data diproses dari lima parameter (pH tanah, suhu tanah, suhu udara, kelembapan tanah dan udara), melalui tahap preprocessing dan pelabelan kelas menggunakan fuzzy logic, lalu diuji pada berbagai skenario pembagian data dari 90:10 hingga 60:40 untuk menemukan konfigurasi paling optimal.

Model terbaik diimplementasikan ke dalam sistem berbasis web bernama SoilML.
