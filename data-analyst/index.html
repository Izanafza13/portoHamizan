Proyek analisis data

Analisis penyewaan sepeda

Analisis data penyewaan sepeda Capital Bikeshare di Washington D.C. tahun 2011 sampai 2012, dilengkapi dashboard interaktif.

PythonStreamlitJupyter Notebook
Lihat di GitHub ↗Lihat demo ↗
Lihat poin

Temuan

≈57,9%penyewaan hari kerja ada di tujuh jam sibuk
≈63,0%penurunan saat hujan atau salju ringan
≈64,9%pertumbuhan penyewaan 2012 dibanding 2011
  • Hari kerja memuncak sekitar pukul 08.00 dan 17.00. Di akhir pekan dan libur, jam sibuk yang sama hanya ≈34,8%
  • Cuaca berkabut menurunkan penyewaan ≈17,2%. Pengguna casual paling terdampak oleh hujan atau salju ringan (turun ≈80,8%, registered ≈58,7%)
  • Penyewaan naik di semua bulan pada 2012, dengan pertumbuhan terendah di Juni (≈41%)

Langkah analisis

  • Merumuskan tiga pertanyaan bisnis: jam sibuk, dampak cuaca, dan pertumbuhan tahunan
  • Membersihkan data penyewaan per jam dan harian
  • Mengelompokkan data: segmen waktu, tingkat permintaan harian, dan rentang suhu
  • Menganalisis di Jupyter Notebook
  • Menyajikan hasil dalam dashboard Streamlit
Proyek riset

Klasifikasi kesesuaian lahan padi

Dashboard Streamlit untuk mengklasifikasikan kesesuaian lahan sawah berdasarkan pH tanah, suhu tanah, dan kelembaban udara, dengan model Random Forest, MLP, serta Hybrid Soft Voting dan Stacking. Dilengkapi interpretabilitas SHAP dan LIME serta prediksi interaktif.

Temuan

4model dibandingkan
3fitur: pH, suhu tanah, kelembaban udara
3kelas kesesuaian lahan
  • Lahan diberi label rule-based: Sangat Cocok, Kurang Cocok, dan Tidak Cocok
  • Model dievaluasi dengan akurasi dan confusion matrix
  • Fitur paling berpengaruh dijelaskan dengan SHAP, dan prediksi per sampel dengan LIME

Langkah analisis

  • Upload data CSV dan pilih fitur
  • Statistik deskriptif data
  • Imputasi nilai kosong dengan KNN dan pelabelan rule-based
  • Split data, SMOTE, dan normalisasi
  • Pelatihan dan evaluasi model
  • Interpretasi model dengan SHAP dan LIME
  • Prediksi interaktif dari input manual
